## Run SRecord in GitHub Codespaces

1. Open the repository on GitHub.
2. Select **Code > Codespaces > Create codespace on main**.
3. Wait for the development container to finish building.
4. GitHub will forward port **6080** as **SRecord Desktop (noVNC)**.
5. Open that forwarded port in the browser. The Qt desktop and SRecord should start automatically.
6. If SRecord is not visible, run this command in the Codespaces terminal:

```bash
bash .devcontainer/run-srecord.sh
```

The Codespace uses the repository's `sinfo.db` SQLite database. The application can therefore be built and tested without installing Qt on the local computer.

## Windows offline package

GitHub Actions can create a self-contained Windows package.

1. Open **Actions** in the repository.
2. Select **Windows Offline Package**.
3. Select **Run workflow**.
4. When the workflow succeeds, open the workflow run.
5. Download the artifact named **SRecord-Windows-Offline**.
6. Extract `SRecord-Windows-Offline.zip`.
7. Keep `sinfo.db` beside `SRecord.exe` and run `SRecord.exe`.

The package includes the Qt runtime files and SQLite driver generated by `windeployqt`, so normal desktop use does not require an Internet connection.

> Important: `sinfo.db` is currently stored in this repository and is copied into the offline package. If it contains real student or personal records, replace it with a sanitized/template database before distributing the repository or package publicly.
